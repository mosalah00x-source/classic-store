# Contract Gaps & Specification Mismatches

This document logs all identified mismatches, missing endpoints, and contract gaps between the static UI prototype, the OpenAPI specification, and the Spring Boot backend implementation.

| ID | Description | Evidence | Impact on Frontend | Priority | Suggested Owner |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **GAP-01** | **CORS unconfigured on backend** | `backend/src/main/java/com/classicstore/common/config/SecurityConfig.java` (no `.cors()` configuration) | Cross-origin API calls directly from browser (`http://localhost:3000`) will be blocked by CORS policy. Frontend must proxy requests or backend must enable CORS. | **P0** | Backend |
| **GAP-02** | **Missing Address mutation endpoints (missing in spec AND backend)** | `docs/api/openapi.yaml:294-355` and `AddressController.java` only define/implement `GET`, `POST`, `GET /{id}`. Missing `PUT /{id}`, `DELETE /{id}`, `PATCH /{id}/default` in BOTH specification and backend code. | Users cannot edit, delete, or change default address via API. | **P1** | Backend |
| **GAP-03** | **Missing Categories Tree API** | Prototype requires header mega menu categories. No `GET /categories` or `GET /categories/tree` endpoint exists in `openapi.yaml` or backend (only `GET /products?categoryId=...`). | Frontend mega menu and category filters cannot fetch category list dynamically from API. Must be mocked or added to spec/backend. | **P1** | Product / Backend |
| **GAP-04** | **Missing Governorates & Cities Reference API** | Checkout & address forms require governorate and city dropdowns (`governorateId`, `cityId`). No `GET /governorates` or `GET /governorates/{id}/cities` exists in `openapi.yaml` or backend. | Address forms cannot populate Egyptian governorates/cities from API. Must be mocked or added to spec/backend. | **P1** | Product / Backend |
| **GAP-05** | **Missing Wishlist / Favorites API** | Prototype UI includes wishlist functionality (heart icon toggle). No wishlist endpoints exist in `openapi.yaml` or backend. | Wishlist functionality must remain client-side (`localStorage`) until backend adds wishlist endpoints. | **P2** | Product |
| **GAP-06** | **Flyway Migrations Disabled in Application YML** | `backend/src/main/resources/application.yml` line 17 (`spring.flyway.enabled: false`). | Local or staging backend deployment will not auto-apply database migrations unless explicitly enabled or run via CLI. | **P1** | Backend |
| **GAP-07** | **SPEC-ONLY Business Domains** | Catalog, Cart, Checkout, Orders, Payments, Returns, and Admin domains have NO Java controllers/services implemented (only `package-info.java` exists). 19 operations are spec-only. | Frontend tasks T11-T13, T15-T18, T20-T25 cannot connect to real backend; must rely on MSW / mock server. | **P1** | Backend |
| **GAP-08** | **Address DTO Field Name Alias (`line1` vs `street`)** | `AddressInput.java` accepts `line1` and maps it to `street`, and `AddressResponse.java` returns both `line1` and `street`. `openapi.yaml` only declares `street`. | Frontend should use `street` field consistently as declared in OpenAPI. | **P2** | Backend / Frontend |
| **GAP-09** | **Missing Reservation Countdown Expiry in Cart/Order Schemas** | DB schema has `inventory_reservations.expires_at`, but OpenAPI `CartResponse` and `OrderResponse` do not expose reservation expiration time to end user. | Frontend cannot display real-time reservation countdown timers on checkout/cart without backend schema update. | **P1** | Product / Backend |
| **GAP-10** | **Rate Limiting Not Implemented** | `AuthService.java` line 119 has `// TODO: Rate limiting on login endpoint`. | Login and registration endpoints are vulnerable to brute-force attacks if not rate limited at gateway / proxy level. | **P1** | Backend / DevOps |
| **GAP-11** | **Missing Payment Creation Endpoint** | `docs/api/openapi.yaml` & `com/classicstore/payment/` contain no `POST /orders/{orderId}/payments` endpoint to initiate online payment or generate gateway URLs. | Blocks Task T17 for online payment handling (Credit Card, Fawry, Valu). | **P0** | Backend |
| **GAP-12** | **Missing Cart Read & Guest Cart Merge Endpoints** | `docs/api/openapi.yaml:373-450` lacks `GET /carts/{cartId}` to read cart contents, and lacks guest cart merge on login (`POST /carts/merge` or login guest token). | Frontend cannot read existing carts on refresh or merge guest cart items into customer account upon login. | **P0** | Backend |
| **GAP-13** | **Missing Customer Order History List Endpoint** | `docs/api/openapi.yaml:630` only defines `GET /orders/{orderId}` for single order retrieval. No `GET /orders` or `GET /me/orders` list endpoint exists. | Blocks Task T20 (Customer Order History). | **P0** | Backend |
| **GAP-14** | **Missing Customer Profile Read Endpoint** | `docs/api/openapi.yaml:294` only defines `/me/addresses`. No `GET /me` or `GET /auth/me` exists to read user profile details (name, email, phone). | Frontend cannot display user profile info in account area or header without decoding JWT or adding endpoint. | **P1** | Backend |
| **GAP-15** | **Missing Catalog Attribute Filters & Product Gallery/Category/Stock Fields** | `GET /products` parameters omit attribute filters. `ProductSummary` / `ProductDetail` omit image gallery array (`images`), category details, and numerical stock counts. | Product list page cannot filter by attributes; product detail page cannot render multiple images or stock count. | **P1** | Product / Backend |
| **GAP-16** | **Missing Staff / Admin List Endpoints** | `docs/api/openapi.yaml` lacks `GET /admin/orders` and `GET /admin/returns` list endpoints for staff/admin dashboard views. | Staff/admin UI cannot list orders or return requests. | **P1** | Product / Backend |
| **GAP-17** | **Guest Order Tracking Exposes Token in URL Path** | `docs/api/openapi.yaml:598` defines `GET /guest/orders/{token}` with token in path parameter, violating Standing Rule 9 ("No tokens in URLs"). | Exposes sensitive guest tracking tokens in browser history and proxy access logs. | **P0** | Backend |
