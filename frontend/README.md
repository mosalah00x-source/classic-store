# ClassicStore Storefront (`/frontend`)

This directory contains the production-grade Next.js App Router application for the ClassicStore e-commerce storefront.

---

## 1. Prerequisites

- **Node.js**: Active LTS (`v22.22.1` or `>=22.0.0`), configured via `.nvmrc`.
- **Package Manager**: `pnpm` (v10.30.3 pinned via `packageManager` in `package.json`).

---

## 2. Installation & Setup

To set up the frontend environment, copy `.env.example` to `.env.local` and install dependencies with frozen lockfile:

```bash
cd frontend
cp .env.example .env.local
pnpm install --frozen-lockfile
```

## 5. Mock vs. Real Backend Switching Strategy (T07)

The application communicates with the backend via the Next.js Backend-For-Frontend (BFF) layer (`/api/*`).
Switching between Mock Service Worker (MSW) mocking and the real Spring Boot backend will be controlled via `NEXT_PUBLIC_API_MOCKING`:

- **Mock Mode (`NEXT_PUBLIC_API_MOCKING=true`)**: BFF routes and client components receive mock responses generated by MSW handlers in `src/mocks/`.
- **Real Mode (`NEXT_PUBLIC_API_MOCKING=false`)**: BFF route handlers forward requests server-to-server to `API_BASE_URL` (Spring Boot API at `http://localhost:8080/api/v1`).

---

## 6. Strict Development Rules

- **NO Backend Modifications**: Code, database migrations, or OpenAPI specifications inside `/backend` or `docs/api` MUST NEVER be edited from this frontend branch (`front-end-Development`).
- **Layer Import Boundaries (ADR-010)**: `app` -> `features` -> `shared`. Features cannot import other features. Shared cannot import features or app layer.
- **Server-Only Protection**: All modules inside `src/server` or server configuration files MUST import `'server-only'`.
- **Exact Money Formatting**: Money fields must remain formatted strings with 2 decimal places. Floating-point conversions (`parseFloat`, `Number`, `Math`) on money identifiers are prohibited by ESLint.
