# ADR-003: Data Layer & State Management Strategy

* **Status**: ACCEPTED
* **Date**: 2026-03-30
* **Scope**: API Code Generation, Server State, Client Mutations & Global UI State

---

## Context
To prevent API specification drift and manage data fetching across Server and Client Components efficiently, we need a unified data layer architecture.

---

## Decision
1. **Type-Safe API Client Generation**:
   - Generate TypeScript types and fetch helpers directly from `docs/api/openapi.yaml` on `main` using `openapi-typescript` and `openapi-fetch`.
   - CI script syncs schema updates automatically from `origin/main`.

2. **Data Fetching Split**:
   - **Server Components**: Use native `fetch` wrappers generated by `openapi-fetch` with Next.js cache control and tag revalidation.
   - **Client Components**: Use **TanStack Query (React Query)** exclusively for client-side mutations (e.g., adding to cart, submitting forms) and optimistic UI updates.

3. **Global UI State**:
   - Use **Zustand** only for client-only UI state (e.g., cart drawer toggle, mobile navigation drawer open/close, active modal triggers).
   - Domain model data (products, cart items, user profile) is NOT stored in global state stores; it is managed by server cache or TanStack Query.

4. **Standardized Error Handling**:
   - All API errors are mapped through a single `ApiError` class that parses error responses into structured `code` enum, status code, and localized error messages.

---

## Consequences
* **Positive**:
  - Compile-time type safety for every API request/response.
  - Zero manual DTO interface duplication.
  - Minimal state overhead; no complex Redux/Thunk boilerplate.
* **Negative**:
  - Requires automated generation step (`npm run generate:api`) whenever OpenAPI spec changes.

---

## Alternatives Considered
1. **Redux Toolkit**: *Rejected*: Heavy bundle size overhead and unnecessary for server-component-heavy App Router architecture.
2. **Manual `fetch` / `axios` Calls**: *Rejected*: High risk of spec drift and untyped payload bugs.
